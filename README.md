# 科学の実験室 — science-study

世界の解像度を上げ、「なぜそうなるのか」を視覚と操作で理解するための個人実験室です。
例えば、道の上の1秒ごとの位置をグラフの点へ移し、同じペースの動きが直線になる理由を見ます。
光では、ストローの図から、人の列の到着順と傾きを手がかりに水面で光が曲がる仕組みへ進み、同じストローの図へ戻ります。
図を途中で止めたり、条件を変えて比べたりして、各部分の変化と全体の関係をたどれます。
React・TypeScript・Vite・TanStack Router による単一の SPA です。

## 探索する

- `/`：分野と概念のつながりから興味のある入口を選ぶ。
- `/mechanics`：道の上の場所、1秒に進む量、進み方の変化から、位置・速度・加速度をつなぐ。
- `/mechanics/motion`：なぜ一定の速度が位置のグラフの直線になるか。場面選択と22秒の説明アニメーション、出発点・速度の比較。
- `/mechanics/acceleration`：なぜ時間の二乗と½が現れるか。速度の面積を長方形と三角形に分け、時間と加速度を操作する。運動の再生では負の加速度や反転も扱う。
- `/optics`：水中のストローの見え方と、物から目へ届く光の道筋をつなぐ入口。
- `/optics/reflection-refraction`：なぜ速さの違いが向きの違いになるか。ストロー・人の列・波の目印と光の向き・ストローの四場面をたどる。電場・干渉・位相と幾何学の作図は任意で開き、光線図では反射・屈折・全反射を操作する。

全教材は「全体像 → 仕組みの可視化 → 条件を変える → 任意で式と前提を開く」という構成です。
光学の全体像にはストローの光路を添え、仕組みの四場面では図と短い説明を隣り合わせに置きます。
四場面はタブで選び、図の重ね合わせ、条件、時間の操作を役割ごとに分けます。
狭い画面では同じ場面の図・操作・説明を縦に読み、途中の時刻を選んでも両端の状態を比べられます。
光線図は「まっすぐ入る・斜めに入る・水側へ戻る」の場面を直接選べます。
出発側と進む先を並べ、角度はスライダーと数値入力で変更でき、速さと屈折率の表は条件操作の後に任意で開けます。
どの入口にも直接移れます。
予想、理解度チェック、採点、説明課題、完了チェックはありません。
個人の理解の評価や履歴の自動記録は行いません。

## 教材の設計

操作部品はMantineの標準と共通テーマを使い、説明の順序・図と言葉の対応・条件変更の分かりやすさを改善します。
光学の改善で採用した[説明と操作を一緒に設計する手順](docs/content-design.md#説明と操作を一緒に設計する)を、教材の追加・改善で使います。
中心の問いを因果の関係に分け、図で指せる対象を決めてから、場面・見方・条件・時間の操作と文章を組み立てます。
「観察と説明の流れ」には、図・説明・操作の配置と、切り替え時に保持・停止・初期化する状態も残します。
その記録の欠落はテストで検出し、説明の意味と使いやすさは実画面で確認します。

身近な感覚から始め、知っている場面の関係を、新しい対象へ対応させます。
同じ目印や操作を保って図をつなぎ、たとえが対応しない点も示して、元の現象へ戻ります。
同じ動きをグラフへ移す橋渡しも使います。
図の前には見る対象を示し、図の後には名前と分かる関係を説明します。
例えば「波面は同じ位相の面」と書く前に、繰り返しの段階と、その段階がそろう場所を図で示します。
一つの場面で扱う関係を絞り、時間や条件を操作して比較できるようにします。
この方針を [教材の設計契約](docs/content-design.md)、[AGENTS.md](AGENTS.md)、共通の `Lesson` と必須の `LessonContent` に反映しています。
教材の新規作成・修正では、最初に設計契約と[科学教材の文章と図の規範](docs/writing-guidelines.md)を読みます。
[教材設計テンプレート](docs/templates/lesson.md)に沿って、身近な感覚から概念への橋渡し・概念の導入・観察と説明の流れを三つの表で `lesson.md` に記録し、実装と同時に更新します。
観察と説明の緩急を文章と図に適用し、科学的な正確さと必要な橋渡しを優先します。
利用者が毎回同じ説明方針を指示し直す必要がないよう、全ページの継続的な要件として扱います。
図の演出だけで原因を説明したことにせず、式・単位・成立条件・資料と照合します。
奥行きの理解が必要になったら3Dを選べます。
光の波面はSVGの奥行きのある投影図も使い、Three.jsは追加していません。

力学のモデルは m・s を使い、右向きが正です。
解析式を評価し、描画側でピクセルに変換します。
p5.jsは運動の描画で動的に読み込みます。
物理時刻は0〜10秒。
再生・停止・初期化・時刻指定ができます。
説明アニメーションは x₀ = 0 m、v = 5 m/sの固定例で、操作する運動とは独立しています。
説明の2〜6秒に物理時刻が0〜4秒まで進み、その後は停止して関係を示します。
初めは停止し、非表示のタブや離脱時に停止・破棄します。
動きを減らす設定では場面選択で静止画を見られます。
加速度の面積図は初速度2 m/sに固定し、運動の条件とは独立しています。

光学のモデルは角度 rad・速さ m/s。
表示は ° とピクセルです。
光線図は条件ごとの解析式の可視化で、波面の図は解析式による幾何学的な作図です。
これらの静止した条件図は物理時刻を再生しません。
主な仕組みの図は、静止場面と説明の時間を選べます。人の列は固定の向きに歩く模式図で、光の曲がる角度の計算には使いません。
ストローの図は近接した二光線の延長の交点を、一点の見える位置の近似として示します。
任意の詳細のアニメーションは、説明の時間を光の周期や境界の到達時間に変換して、非常に遅く描きます。
波面図は空気→水またはガラスの0°・30°・45°・60°に限定し、光線図とは条件が独立しています。
光線図には物質の入れ替え、臨界角、初期値への復帰があります。
光線図では平らな境界と一様・等方的な透明物質を仮定し、反射・透過の強さ、偏光、分散、干渉、回折を省きます。
基礎の説明図では、別の単純化したモデルで二つの光の干渉を扱います。
実測データや電磁場の数値シミュレーションではありません。

## 開発・検証

Node.js 24 と pnpm 11 を使用します。

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

`pnpm test:watch` で継続実行できます。
テストはモデルの科学的な性質（周期、伝わる速さ、位相と値の違い、場の関係、干渉、波面）、時刻制御、教材の構成を開発者が検証するものです。
教材ディレクトリを自動で探索し、`lesson.md` の設計表の欠落・空欄・未記入も検出します。図・説明・操作の配置と状態の設計も検査対象です。
文章の質や科学的な正確さを自動判定するものではなく、制作者のレビューと組み合わせます。
学習者向けのテストではありません。
ブラウザでは操作・後片付け・狭い画面を確認します。
実装の正しさ、現実へのモデルの適合、学習効果はそれぞれ別に検証する必要があります。

## 構成と追加

- `src/routes/`：URL とページの接続。
- `src/app/`：全体の地図、分野の入口、ナビゲーション。
- `src/components/Lesson.tsx`：全教材の共通構成と、必須の内容契約。
- `src/experiments/<分野>/<テーマ>/`：meta、lesson.md、純粋なモデルとテスト、仕組みの図、条件操作、ページの組み立て。
- `src/experiments/mechanics/shared/`：2題で使う時刻制御・描画・グラフ・操作部品。
- `tests/`：Node.jsで教材の設計記録を読む自動検査。科学モデルとUIのテストは各実装の近くに置きます。
- `notes/`：任意の個人メモ。[テンプレート](notes/journal/TEMPLATE.md)の一部だけ使ってもよく、記入は探索の条件ではありません。保存・同期機能は設けません。

[設計と追加手順](docs/architecture.md)・[概念の地図](docs/learning-map.md)を参照してください。
`src/routeTree.gen.ts` は手で編集せず `pnpm build` で生成し、Git に含めます。
公開には任意のURLを `index.html` に返す SPA フォールバックが必要です。
個人メモの公開範囲は別途決めます。
