# 光の反射と屈折

問い：境界に斜めに入った光は、どの向きへ進む？

科学の目標：反射と屈折を光の進む側・法線からの角度・速さで区別する。
実装の目標：入射角と物質を変え、反射・屈折・全反射を解析式の光線図で確認する。
本人の予想は操作前に選ぶ。教材の説明や計算結果とは区別し、学習記録は捏造しない。

## モデル・単位

- 反射の法則：`θᵣ = θ₁`。
- スネルの法則：`n₁ sin θ₁ = n₂ sin θ₂`。
- 屈折率：`n = c / v`。`c = 299,792,458 m/s`、`v` は物質中の光の速さ [m/s]。
- `n₁` は出発側、`n₂` は進む先の屈折率（単位なし）。
- 角度はすべて境界に垂直な法線から測る。モデルは rad、表示は °。
- モデルは符号付き角度 `−π/2 < θ₁ < π/2` を受け付ける。UI は0〜80°。
- 光線の方向は単位ベクトル（単位なし）。yは上向き。ピクセルへの変換は描画側。
- `n₁ > n₂` で臨界角 `θc = asin(n₂ / n₁)` が存在する。
  `|θ₁| > θc` なら全反射し、屈折光線はない。臨界角ちょうどは屈折角90°で境界に沿う限界。
  浮動小数点誤差に限って `|n₁/n₂ × sin θ₁| = 1` の判定を丸める。
- 同じ屈折率では屈折せず、このモデルでは反射光もない。

初期条件：空気1.00 → 水1.33、入射角45°。反射角45°、屈折角約32.1°。
空気→水では法線に近づく。水→空気では透過する範囲で法線から離れる。
水中では速さが約2.25 × 10⁸ m/sになる。
ガラスの代表値は1.50。同じ物質どうしの設定も選べる。
水1.33 → 空気1.00の臨界角は約48.8°。60°では全反射。
臨界角のボタンでは丸める前の値を条件に設定し、表示のみ小数1桁へ丸める。

## 説明・適用範囲

反射は元の物質側へ跳ね返ること。屈折は別の物質へ進むとき向きが変わること。
水面では両方が同時に起こる。光を波として見ると、斜めの波の前線の一部が先に水へ入り、
そこから速さが変わることで前線の向きが変わる。垂直入射では前線が一斉に到達し、曲がらない。
水中のストローから目へ届く光は水→空気で曲がり、実際と違う位置に見える。

平らな境界と、一様・等方的で吸収のない透明物質を仮定した幾何光学の解析式。
単色光の代表値として空気1.00・水1.33・ガラス1.50を固定する。
波長・温度・ガラスの種類による屈折率の違いは省く。
物体・境界の形の尺度が波長より十分大きい場合の近似。
強さの比（フレネル係数）、偏光、分散、干渉、回折、粗い面の乱反射は扱わない。
全反射時の境界付近のエバネッセント波も描かない。

条件ごとの解析式の可視化。実測でも時間を進める数値シミュレーションでもない。
再生する物理時刻はなく、条件変更で光線図が更新される。線の長さ・太さ・色は速さや強さを表さない。
「初期値に戻す」は物質と角度を戻す。ページ離脱時はResizeObserverを解除する。
全反射時の進む先の速さは物質の性質として表示し、光が透過したという意味にはしない。

## 学習の一周

1. 空気→水の45°で屈折角がどうなるか、本人が予想を選ぶ。
2. 実験を開き、45°・0°を比較する。物質を入れ替え、60°と臨界角も観察する。
3. 式・法線・速さ・成立条件を解説で確認する。
4. 解説を閉じ、反射と屈折の違いとストローの見え方を自分の言葉で説明する。
5. 再挑戦：空気→水、入射角0°。答えは「曲がらず、遅くなる」。図と数値で確かめる。
6. 予想・条件・観察・理解の変化・残った問いを `notes/journal/` のMarkdownに本人の言葉で残す。
