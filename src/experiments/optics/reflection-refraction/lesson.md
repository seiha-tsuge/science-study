# 光の反射と屈折

問い：水面へ斜めに届く光は、速さが変わると、なぜ向きも変わるのか？

入口は、水中のストローが水面でずれて見える場面である。
水中の部分から目へ届く光は、水面で向きを変える。
目へ届いた光の向きをまっすぐ水中へ延ばすと、実際の位置とはずれる。

光が向きを変える仕組みを、各場所で起こる変化と、その変化が伝わる向きに分けて説明する。
初めはひもに付けた印の上下と、山の形の移動を比較する。
この具体像から「波」を導入し、六つの場面で光の電場、干渉、位相、波面、水面への到達をつなぐ。
実装の目標：入射角と物質を変え、反射・屈折・全反射を解析式の光線図で確認する。
全体像・基礎の図・条件操作は最初から表示する。
距離を使った作図と、式・モデルの前提は任意で開く。

## 概念の導入

| 概念 | 名前を付ける前に見るもの | 図で指す対象 | 混同を避ける比較 |
| --- | --- | --- | --- |
| 波 | ひもに付けた印が上下し、山の形が右へ進む様子 | 固定した横位置のオレンジの印と、青いひもの形 | 物質の動きと、変化の伝わる向きを区別する |
| 電場 | 正の電気を帯びた小さな粒に、どちらへどれだけ力がはたらくか | 各場所の青い矢印 | 矢印の長さは場の値で、物体の位置や光の粒子の軌道ではない |
| 磁場 | 電場だけの表示へ、奥と手前の向きを重ねる | 緑の記号と、その向きの凡例 | 電場、磁場、伝わる向きは別の方向で、大きさを同じ長さの単位で比べない |
| 干渉 | 二つの隙間から届く光が壁の一点で重なる様子 | 二つの電場の時間変化と、黒い合成の線 | 変化がそろう場合と逆の場合を比較し、瞬間の場の値と平均の強さを区別する |
| 位相 | 二つの場所の電場の変化と、一周の中の位置 | AとBの電場を表す点、それぞれの円の上の点 | 同じ高さでも、上がる途中と下がる途中は別の位相になる |
| 波面 | 電場が同じ進み具合になる連続した場所 | 緑の断面と、奥行きのある緑の面 | 条件に合う場所の集合と、実在する物質の表面や糸を区別する |
| 光線 | 波面を正面から突き抜ける進む向き | 面を通る黒い矢印 | 波面の向きと進む向きを区別し、平面波の条件で垂直になることを示す |
| 境界と法線 | 空気と水が接する水面と、その水面に90°で立つ基準線 | 灰色の水面と、任意で重ねる破線 | 水面に垂直な法線と、緑の波面に垂直な光の向きを描き分ける |

## 観察と説明の流れ

| 場面 | 注目する対象 | 観察と操作 | ここで分かる関係 |
| --- | --- | --- | --- |
| 何が伝わる？ | ひもの印と山の形 | 再生と停止、時間指定で二つの動きを見る | 波では、その場所の変化と変化の伝わる向きを分けて考えられる |
| 光で変わるもの | 各場所の場の矢印 | 時間を変え、任意で磁場の向きを重ねる | 光では電場と磁場が変わり、ひものような物質がなくても伝わる |
| 波と考える手がかり | 壁の一点で重なる二つの電場 | 二つの変化をそろえる場合と逆にする場合を切り替える | 光の明暗を、波の強め合いと打ち消し合いとして扱える |
| 同じタイミングとは | AとBの場所と一周の位置 | 同じ進み具合、¼周、½周、高さだけ同じ条件を比較する | 同じ値と同じ位相は別で、繰り返しのどの段階かを比較する必要がある |
| 場所をつないで見る | 同じ進み具合の場所 | 上からの断面と空間の面を切り替える | 波面は同じ位相の面で、この平らな波の光線はその面に垂直になる |
| 空気と水の間 | 一つの波面と水面 | 斜めとまっすぐの入射を比較し、3秒付近で停止する | 先に届いた部分から速さが変わり、斜めの波面と光の向きが変わる。まっすぐでは速さだけが変わる |
| 光の道筋へ戻る | 光線図の境界前後の向き | 角度と物質を変え、水から空気へ進む場合も見る | 水中のストローから目へ届く光の向きが、水面で変わることにつながる |

中心の問いは、水面への到達時刻の違いと、各部分の波面に垂直な光の向きを対応させて説明する。
波として扱う観察の手がかりは、干渉の場面で示す。
ストローの見え方への接続は光の道筋として説明し、ストロー自体の位置を再現する画像はここでは描かない。
物質中の速さが決まる微視的な理由と、光の粒子としての検出は別のモデルにつなぐ。

この理想的な周期的な波では、各場所で上がる、上の端、下がる、下の端を繰り返す。
一周のどの段階にいるかが「位相」である。
各場所には位相があり、二つの場所が同じ段階か、別の段階かを比べる。
ここで「結ぶ」は条件に合う場所を図の上でつなぐことで、糸や物体が空間をつなぐ意味ではない。
波面の三次元の面は、SVGの投影で奥行きを描く。
実在する壁や水の表面そのものではなく、同じ位相の場所の集合。

一度に一つの場面を表示し、短い説明を図の近くに置く。
好きな場面へ直接移れ、予想や回答の入力は不要。
新しい用語を未説明の用語で定義し続けない。
位相の円は上の図のAとBの電場の変化に、面の投影は上から見た断面に対応させる。
図の前には対象と見る場所を示し、図の後で名前と分かる関係を説明する。

## 基礎のアニメーションのモデル・式・尺度

`model.ts` に、ひもの理想的な波、真空中の平面電磁波、位相、二波の合成、一つの波面の境界通過を置く。
純粋な解析式の評価であり、実測データや電磁場の数値シミュレーションではない。

- 正弦波の進み具合は `φ = 2π(x/λ − t/T)`、値は `sin φ`。位相はrad、位置x・波長λはm、時刻t・周期Tはs。
- ひもの変位は `y = A sin φ`、λ = 1 m、T = 2 s、A = 0.2 m。横の座標を固定した印で物質の動きと形の移動を分ける。実際のひもの運動全般を再現するものではない。
- 光は真空中の、同じ方向に偏った単色の平面波。λ = 600 nm、T = λ/c ≈ 2.00 fs、E₀ = 1 V/mの説明例。
- 電場は `Eᵧ = E₀ sin φ` [V/m]、磁場は `Bz = Eᵧ/c` [T]。伝わる向きは+x。Eの向きはy、Bの向きはzで互いに直交する。
- 電場の矢印は、正の電気を帯びた小さな粒に力がはたらく向きと大きさの表示。磁場の記号は向きのみで、EとBの大きさを同じ長さの単位で比べない。
- 位相の円は一周の中の位置を示す説明用の対応図で、物体の軌道ではない。同じ値と違う変化の向きの例はφ = π/6と5π/6。
- 波面は同じ位相の場所がつくる連続した面。ここでは電場が最大になる平面を選び、断面と空間の面を示す。平面波・一様等方的な空間の条件で、光線はその面に垂直。
- 干渉は、光源・二つの隙間・壁の模式図で観察場所を示した後、同じ振れ幅・周波数・偏り方向で関係が安定した二つの波をその場所で足す。位相差δなら周期平均の強さは `I/I_single = 2 + 2 cos δ`。δ = 0では4、δ = πでは0。瞬間の電場の上下の符号とは区別する。壁全体の明暗分布は描かない。

説明の時間は0〜8秒。
最初の五場面は説明の2秒を一周期に対応させ、光では約10¹⁵倍に遅くする。
水面の場面は、横の幅1.2 mの範囲に一つの波面を選ぶ幾何学的な図。
縦横の空間の縮尺は同じにする。
説明8秒を物理時刻 `1.2 m / c ≈ 4.00 ns` に対応させる。
上側の波面の位相距離をs = −0.4 m + ctとし、任意の横位置xで `y = (sinθ₁ x − s)/cosθ₁`。
水に入った部分では `y = (sinθ₂ x − s v₂/v₁)/cosθ₂` とし、スネルの法則によって水面で連続につながる。
斜め入射45°と垂直入射0°を切り替える。
各部分の波面に垂直な黒い矢印で、光の進む向きも示す。
矢印の長さは速さを表さない。
反射光・場の強さの変化・干渉をこの境界図には含めない。

初期状態は最初のひもの場面、時刻0・停止。
再生・停止・初期化・時刻指定・場面選択ができる。
場面・比較条件の変更で停止して時刻0へ戻す。
非表示のタブでは停止し、離脱時にRAFとイベントリスナーを解除する。
動きを減らす設定では再生を無効にし、時間スライダーで静止した場面を選べる。
光の粒子としての検出や、物質中の速さが決まる微視的な相互作用は、さらに別のモデルが必要。

## 光線図のモデル・単位

- 反射の法則：`θᵣ = θ₁`。
- スネルの法則：`n₁ sin θ₁ = n₂ sin θ₂`。θ₁は境界へ届く光、θ₂は向こう側へ進む光の、法線との角度。sinは角度に対応する比で、光の向きの境界に沿う成分を表すのに使う。
- 屈折率：`n = c / v`。`c = 299,792,458 m/s`、`v` は物質中の光の速さ [m/s]。
- `n₁` は出発側、`n₂` は進む先の屈折率（単位なし）。真空中と物質中の光速の比で、大きいほど物質中の光は遅い。
- 角度はすべて境界に垂直な法線から測る。モデルは rad、表示は °。
- モデルは符号付き角度 `−π/2 < θ₁ < π/2` を受け付ける。UI は0〜80°。
- 光線の方向は単位ベクトル（単位なし）。yは上向き。ピクセルへの変換は描画側。
- `n₁ > n₂` で臨界角 `θc = asin(n₂ / n₁)` が存在する。asinはsinの値から角度を求める操作。臨界角は屈折角が90°になる入射角。
  `|θ₁| > θc` なら全反射し、屈折光線はない。
臨界角ちょうどは屈折角90°で境界に沿う限界。
  浮動小数点誤差に限って `|n₁/n₂ × sin θ₁| = 1` の判定を丸める。
- 同じ屈折率では屈折せず、このモデルでは反射光もない。

初期条件：空気1.00 → 水1.33、入射角45°。
反射角45°、屈折角約32.1°。
空気→水では法線に近づく。
水→空気では透過する範囲で法線から離れる。
水中では速さが約2.25 × 10⁸ m/sになる。
ガラスの代表値は1.50。
同じ物質どうしの設定も選べる。
水1.33 → 空気1.00の臨界角は約48.8°。
60°では全反射。
臨界角のボタンでは丸める前の値を条件に設定し、表示のみ小数1桁へ丸める。

## 説明・適用範囲

境界へ届く光が入射光、元の物質側へ戻る光が反射光、向こう側へ進む光が屈折光である。
水面では、一部が反射し、一部が水中へ進む。

波面が斜めに水面へ届く場合、一部が先に水へ入る。
先に入った部分から速さが小さくなり、波面の向きが変わる。
この波面に垂直な光の進む向きも変わる。
水面へまっすぐ届く場合は、波面全体が同時に水へ入るため、速さが変わっても向きは変わらない。

ストローから目へ届く光は、逆の水→空気で向きを変える。
目へ届いた向きをまっすぐ水中へ延ばすと、ストローの実際の位置とはずれる。
物体の形の変化と、光の道筋の変化を区別する。

境界は平らで、各物質の性質は場所や方向によらず、光を吸収しないと仮定する。
これが一様・等方的・吸収なしという条件である。
光の道筋を線で扱う近似を幾何光学と呼ぶ。
単色光の代表値として空気1.00・水1.33・ガラス1.50を固定する。
波長・温度・ガラスの種類による屈折率の違いは省く。
物体・境界の形の尺度が波長より十分大きい場合の近似。
強さの比（フレネル係数）、偏光、分散、干渉、回折、粗い面の乱反射は扱わない。
全反射時の境界付近のエバネッセント波も描かない。

条件ごとの解析式の可視化。
実測でも時間を進める数値シミュレーションでもない。
再生する物理時刻はなく、条件変更で光線図が更新される。
線の長さ・太さ・色は速さや強さを表さない。
「初期値に戻す」は物質と角度を戻す。
ページ離脱時はResizeObserverを解除する。
全反射時の進む先の速さは物質の性質として表示し、光が透過したという意味にはしない。

## 波面を段階と条件で見る

波面上の各点から広がる波を考え、それらに触れる面を次の波面とする。
この見方をホイヘンスの作図と呼び、各点から広がる波を二次波と呼ぶ。
Aが先に境界に到達し、Bがまだ空気中にある斜めの波面を考える。
Bが境界上のB′へ届くまでの同じ時間Δtに、Aからは半径v₂Δtの二次波が広がる。
この半円に接してB′を通る線が、新しい波面。
光線はその線に垂直になる。
空気より遅い物質では二次波が進む距離が短く、新しい光線は法線へ近づく。
垂直入射ではAとBが同時に境界に届き、この作図での時刻差は0。
向きは変わらず、速さだけが変わる。
物質中の速さを決める電磁場と物質の相互作用の詳細は、ここでは扱わない。

任意で開く作図は空気→水またはガラス、入射角0°・30°・45°・60°。
境界上のA–B′間を1 mとして比を描く。
波長を1 mに設定した意味ではない。
初期表示は空気→水45°、新しい波面まで見える全体図。
ボタンで到達・進む距離・新しい波面を切り替える。
半円は二次波の断面で、粒子の軌道ではない。
反射光、強さ、干渉、全反射の境界付近の波を含めない。
解析式からの幾何学的な作図であり、電磁場の数値シミュレーションや物理時刻の再生ではない。
光線図の条件とは独立する。
光線図では垂直入射・同じ物質・臨界角・全反射も扱う。
予想・理解度チェック・説明課題は設けない。
