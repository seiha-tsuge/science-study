# 位置と速度

問い：同じ速度で進み続ける物体の位置は、時間とともにどう変わる？

科学の目標：位置と時間のグラフの傾きを速度と対応づけ、符号と初期位置の意味を説明する。
実装の目標：解析式から計算した位置を描画し、条件変更と基準条件の比較を行う。

## モデル

`x(t) = x₀ + vt`、`v(t) = v`、`a(t) = 0`。
位置 x・初期位置 x₀ は m、速度 v は m/s、時刻 t は s。
原点を0 m、右向きを正にする。一直線上で、速度が一定の運動だけを扱う。
物体の形状、衝突、力の変化は扱わない。解析式の可視化で、実測や数値積分ではない。

初期条件は x₀ = 0 m、v = 5 m/s。速度は −10〜10 m/s、初期位置は −20〜20 m。
時間は0〜10秒。比較基準は初期条件から始め、現在の条件を新しい基準にできる。
位置グラフは直線、速度グラフは水平。速度を2倍にすると同じ時間の変位が2倍になる。
初期位置が0でなければ、位置自体が2倍になるとは限らない。

## 自分の言葉で説明する
