# 位置と速度

問い：同じ速度で進み続ける物体の位置は、時間とともにどう変わる？

科学の目標：位置と時間のグラフの傾きを速度と対応づけ、符号と初期位置の意味を説明する。
実装の目標：解析式から計算した位置を描画し、条件変更と基準条件の比較を行う。

## モデル

`x(t) = x₀ + vt`、`v(t) = v`、`a(t) = 0`。
位置 x・初期位置 x₀ は m、速度 v は m/s、時刻 t は s。
原点を0 m、右向きを正にする。一直線上で、速度が一定の運動だけを扱う。
物体の形状、衝突、力の変化は扱わない。解析式の可視化で、実測や数値積分ではない。

初期条件は x₀ = 0 m、v = 5 m/s。速度は −10〜10 m/s、初期位置は −20〜20 m。
時間は0〜10秒。比較基準は初期条件から始め、現在の条件を新しい基準にできる。
位置グラフは直線、速度グラフは水平。速度を2倍にすると同じ時間の変位が2倍になる。
初期位置が0でなければ、位置自体が2倍になるとは限らない。

## 動きから式への説明アニメーション

解説を開くと、22秒の説明を手動で再生できる。解析式の可視化であり、実測や数値積分ではない。
固定条件は x₀ = 0 m、v = 5 m/s。実験の操作条件とは独立している。

| 説明の時間 | 内容 | 物理時刻 |
| --- | --- | --- |
| 0〜2秒 | 座標と出発点。右向きが正 | 0 sで停止 |
| 2〜6秒 | 一定速度で0〜20 mへ進む | 0〜4 sを等倍で進める |
| 6〜10秒 | 過去の1秒ごとの位置に印を付ける | 4 sで停止 |
| 10〜14秒 | どの1秒間も変位は＋5 mと示す | 4 sで停止 |
| 14〜18秒 | 0〜4秒の位置をグラフに対応づける。傾きは5 m/s | 4 sで停止 |
| 18〜22秒 | x = x₀ + vt。0 m + (5 m/s) × (4 s) = 20 m | 4 sで停止 |

表示する過去の位置は t = 0, 1, 2, 3, 4 sに対して x = 0, 5, 10, 15, 20 m。
グラフの線が順に現れる演出は物理時刻を進めない。物体の運動には演出用の緩急を付けない。
一直線上で速度が一定というモデルの前提は実験と同じ。物体の形状、衝突、力の変化は扱わない。
再生・一時停止・初期化・説明の時間指定・場面の選択ができる。
場面の選択はその場面の終わりの静止画を示す。非表示のタブでは停止し、解説を閉じると終了する。
動きを減らす設定では、静止画で各場面を確認する。
