# 加速度

問い：1秒ごとに速度が同じ量ずつ増えると、位置のグラフはどう変わる？

科学の目標：速度の変化率として加速度を説明し、位置と速度のグラフを区別する。
実装の目標：等加速度運動を解析式で可視化し、同じ初期条件の等速運動と比較する。

## モデル

`v(t) = v₀ + at`、`x(t) = x₀ + v₀t + ½at²`。
位置は m、速度は m/s、加速度は m/s²、時間は s。右向きが正。
一直線上で、加速度が時間によらず一定であるという前提。
摩擦・衝突・時間で変わる加速度は扱わない。
解析式の可視化で、数値積分の時間刻みはない。結果を実測とは扱わない。

初期条件は x₀ = 0 m、v₀ = 5 m/s、a = 1 m/s²。
加速度は −2〜2 m/s²、初速度は −10〜10 m/s、初期位置は −20〜20 m。
比較側は常に同じ x₀ と v₀ で、a = 0 m/s²。時間は0〜10秒。
正の初速度と正の加速度では、毎秒の変位が増える。
負の加速度でも必ず減速ではない。速度と加速度の方向が同じなら速さは増える。

## 自分の言葉で説明する

位置のグラフが曲線なのに、速度のグラフはなぜ直線になる？
速度が正で加速度が負のとき、停止後にも加速度が続くとどうなる？

再挑戦：x₀ = 0 m、v₀ = 0 m/s、a = 2 m/s²、t = 3 s。
位置は9 m、速度は6 m/s。最終速度をずっと一定だった速度として使わない。
