# 科学教材の文章と図の規範

## 適用する範囲と優先順位

ホーム、分野ページ、教材の本文、図の注記、操作の説明、教材のMarkdownに適用する。
利用者提供の `japanese-tech-writing` と `cognitive-rhythm-writing` を、科学教材向けに調整した規範である。
原文のすべてをそのまま適用するものではない。

判断がぶつかる場合は、次の順で優先する。

1. 科学的な正確さ。前提、単位、適用範囲、不確実性を保つ。
2. 概念をたどるための足場。対象、比較の基準、必要な中間段階を示す。
3. 注意の配分。図と説明を対応させ、一度に見る関係を絞る。
4. 日本語の表現とリズム。重複を除き、観察と説明の密度を整える。

文章を短くしたり、続きを読みたくさせたりするために、上位の要件を削らない。
[教材の設計契約](content-design.md)と併せて使用する。

## 対象を見てから名前を付ける

新しい概念は、対象を置き、その振る舞いや違いを示してから名前を付ける。
定義に必要な語が未説明なら、その語を図で導入するところまで戻る。
日常語への言い換えで意味が曖昧になる場合は、対象との対応を示して正式な用語を導入する。
導入した用語の意味と呼び方は、その後の場面でも保つ。

一つの段落は一つの関係を扱う。
段落の最初の文で対象を示し、前の段落とのつながりが飛ぶ場合は接続を補う。
接続詞を機械的に付けたり、同じ結論を言い換えて繰り返したりしない。
原因を述べるときは、対象のどの変化が次の変化につながるのかを、文と図で対応させる。

位置と速度の説明であれば、時間、道の上の場所、グラフの点を一度に取り替えない。
同じ物体と目印を保ち、動きとグラフを別の表示としてつなぐ。
例を変える必要があるときは、何を共通にし、何を変えるかを示す。

身近な場面から新しい対象へ移るときは、場面同士の関係を言葉と図でつなぐ。
「人の列のA側」を「波の目印のA側」へ対応させるように、指す対象を保って、置き換えたものを明示する。
たとえの名前だけを置かず、「どちらが先に届くか」「同じ時間にどれだけ進むか」など、渡す関係を書く。
対応しない性質は、その違いが効く図の近くに示す。
その後で元の現象へ戻り、新しい見方で何が説明できるかを示す。
具体的な設計手順は[身近な感覚から概念へ橋を渡す](content-design.md#身近な感覚から概念へ橋を渡す)に従う。

## 観察と説明に緩急を作る

緩急は、短文や劇的な語尾を増やすことではなく、注目する対象と説明の役割を切り替えることとして扱う。
次の流れを基本とし、場面によって必要な部分を選ぶ。
すべての場面を同じ型に押し込まない。

| 役割 | 図と操作 | 文章の役割 |
| --- | --- | --- |
| 対象を見る | 動く前の対象と目印を示す | どこを見るかを短く示す |
| 違いを見る | 同じ基準で時間、条件、視点を変える | 変わったものと変わらないものを示す |
| 関係を整理する | 対応する場所や量を強調し、停止できるようにする | 見た関係に名前を付け、理由と条件を説明する |
| 現象へ戻る | 元の場面や別の条件と対応させる | 最初の現象について何が説明できたかを示す |

短い観察文の後で必要な理由を説明し、関係がまとまったところで止まれるようにする。
密な説明が続く場合は、同じ図の注目箇所を絞った表示や、確認できた関係を示す短い文を挟む。
段落数や文字数だけで機械的に区切らない。

本文で立てた問いは、その場面や教材の中で、答えと扱える範囲を示す。
対象に残る本当の疑問は次の概念へつなげられるが、続きを読ませるために答えを隠さない。
問いは説明の入口に使い、学習者の予想、回答、説明の提出を求めない。

科学的な結論に演出用の迷いや確信を混ぜない。
仮説や歴史的な考えを扱う場合は、誰の仮説かと、何が確認されたかを分ける。
利用者や書き手が実際に経験していない思い込み、驚き、発見の物語を捏造しない。

## 必要な案内と説明を残す

図の対象や読み方に役立つ案内は残す。
例えば「横軸は時間」「青い印の横の位置は固定」「このボタンは磁場の向きを重ねる」は、表示と内容を対応させるために必要である。
範囲や操作の案内を、本文自身の話だからという理由だけで削らない。

対象の新しい情報がなく、読み方の案内にもならない進行実況や称賛は省く。
「重要な関係を深く理解しましょう」だけで終えず、対象のどの関係を示すのかを書く。
同じ場面を要約し直す文や、想像した読者の感想への応答で段落を増やさない。
短い決め台詞、対句、修辞疑問、空虚な強調で説明を置き換えない。

初めて見る概念の橋渡しは、冗長さと区別する。
「読者が自力で補える」と仮定して、前提、比較軸、導出に必要な一歩を省略しない。
補足を任意で開く領域に移す場合も、現在の図を読むために必要な定義と基準は近くに残す。

## 科学的な説明を保つ

- 観察された事実、モデルから計算した値、説明のための模式図、仮説を区別する。
- 一つの例が支える範囲を超えて一般化しない。複数の原因を一つの原因にまとめない。
- 「同じ」は、値、位相、方向、単位など、何が同じかを特定する。
- 「垂直」「増える」「遅い」は、基準の面、量、比較対象を特定する。
- 「かもしれない」などの不確実性は、根拠で確定した場合にだけ断定へ変える。
- たとえや図の動きだけを証明とみなさない。式、条件、資料と対応づける。
- 説明の緩急を、物理的な運動のイージングや速さの変更として実装しない。

## 日本語と整形

Markdownの本文は一文一行を基本とし、空行で段落を分ける。
TSXでは、一文ごとに画面上の改行を強制せず、意味のまとまりと狭い画面での折り返しを優先する。
式、表、図のラベルは、それぞれの読み方に合う整形を使う。

初めて定義する語は、太字や図のラベルなどで対象との対応を示す。
以後の言及まで強調を繰り返さない。
色だけに頼らず、名前や線種でも対象を識別できるようにする。

見出しは、問い、対象、整理する関係が分かる句にする。
探索の入口では問いの見出しを、確認した関係を整理する場所では結論の見出しも使える。
結論を隠すことや、見出しの型を統一することを目的にしない。

長い挿入や並列は、括弧、読点、文の分割、表などで整理する。
ダッシュや中黒を機械的に禁止せず、分野で使う名称、数式、単位、書誌情報の表記を保つ。
用語の由来など本筋から外れる補足は、任意の詳細に置ける。

## 制作者の作業とレビュー

1. 中心の問い、具体的な入口、モデルが説明する深さを決める。
2. [教材設計テンプレート](templates/lesson.md)を使い、各 `lesson.md` に「身近な感覚から概念への橋渡し」「概念の導入」「観察と説明の流れ」を記録する。
3. 各場面で、見る対象、操作、ここで分かる関係をそろえてから、本文と図の注記を書く。
4. 未説明の語、指示語の基準、飛ばした中間段階、回収していない問いを点検する。橋渡しの表と図を照合し、対応する関係と対応しない性質が読み取れるか確認する。
5. 本文の各段落が対象の情報か必要な案内を増やしているか確認し、重複や演出だけの文を除く。
6. Markdown、画面、式の条件と用語を照合する。変更した関係は設計表にも反映する。
7. `pnpm test` で設計表の構造を検査し、操作UIを変えた場合はブラウザで図と言葉の対応と狭い画面を確認する。

ホームと分野ページには教材の設計表を複製せず、具体的な入口と接続先を確認する。
設計表は制作者の記録で、学習者向けの課題や自動的な理解評価ではない。

`lesson-design.test.ts` は教材ディレクトリを自動で探索し、設計表の欠落、空欄、テンプレートの未記入を検出する。
文体、概念の分かりやすさ、図との意味的な一致、科学的な正確さを機械的に保証するものではない。
表を埋めることだけで作業を完了せず、実際の説明と対応させてレビューする。

## 既存の文章に適用する例

教材の導入、本文、図の説明、操作案内を、同じ対象と基準でそろえる。
READMEと概念の地図は教材への入口を示し、各 lesson.md は実際の説明と設計表を対応させる。
開発者向け文書は責務や手順を明示し、学習者向け本文に実装用のファイル名を混ぜない。
個人メモのテンプレートは任意の記録として保つ。

| 書き直す前の説明 | 対象と関係を補った説明 |
| --- | --- |
| 速度はグラフの傾き | 横に時間、縦に位置を置く。右へ1秒進むごとに5 m高くなる割合が傾きで、速度5 m/sに対応する |
| 速度と時間の面積は変位 | 速度2 m/sが1秒続くと2 m進む。高さが速度、幅が時間の長方形でこの量を表し、時間を細かく分けて足すと面積になる |
| 波面は同じ位相を結ぶ面 | 電場の繰り返しが同じ段階にある場所を緑で示す。この連続した場所の集まりを、断面と奥行きのある面で見せてから波面と呼ぶ |
| 条件を変えて観察しましょう | 速度だけを変えると1秒に進む量が変わる。青い点と灰色の輪を同じ時刻で比較できる |

文の長さだけをそろえるのではなく、必要な一段を補い、同じ内容の重複は減らす。
式や単位、資料の名称、意味が明確な短いラベルは、その表記を保つ。

## 元の規範から調整した点

| 元の考え | 科学教材で採用する形 |
| --- | --- |
| 観察、逡巡、断定、再観察でリズムを作る | 対象を見る、違いを見る、関係を整理する、現象へ戻る |
| 常に未回収の緊張を残す | 各場面で一つの関係を説明し終える。残る本当の疑問は範囲と接続先を示す |
| 思い込みを誘導して崩す | 混同しやすい現象を、事実と条件を保って比較する |
| 読者が補える中間段階を省く | 導入に必要な橋渡しを残し、重複と無関係な詳細を除く |
| 進行案内を削る | 図の読み方、現在の対象、操作と範囲に必要な案内を残す |
| 見出しで結論を先に知らせない | 場所の役割に応じて、問いと結論の見出しを選ぶ |

元の規範は文章の設計方針として扱う。
その規範だけを、認知負荷が下がったという実証の根拠にはしない。
研究に基づく設計判断の参考は[教材の設計契約](content-design.md#参考)にまとめる。
