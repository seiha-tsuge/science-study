# 概念の地図

現在の教材と、この先につながる問いを示す地図である。
道の上の動きと光の道筋を入口に、部分の変化が全体にどうつながるかを見る。
どの教材からも始められる。
「実装済み」は教材があるという意味で、本人の理解を判定した意味ではない。

## 力学の全体像

道の目印を0 mとし、物体の場所を数で表したものが「位置」である。
1秒に位置が何m変わるかを表す「速度」は、向きも含む。
さらに速度が毎秒どれだけ変わるかを見ると、「加速度」につながる。

毎秒同じ量ずつ位置が変わる場合、時刻と位置の点は直線に並ぶ。
速度が毎秒同じ量ずつ増える場合は、後の時間ほど進む量が大きくなる。
速度と時間のグラフでその量を足すと、長方形と三角形の面積として表せる。
三角形の底辺と高さが両方とも時間に比例するため、位置の変化に時間の二乗が現れる。
この先は力と加速度、慣性、運動量、エネルギーへつなぐ。
力の原因は現在の2題の範囲外。

## 光学の全体像

入口は水中のストローの見え方。
ひもの印の上下と波の移動を分け、光では電場と磁場が変わることを導入する。
次に光の重なりで明暗が生まれる干渉を手がかりとして見る。
電場の変化が繰り返しのどの段階にいるかを「位相」と呼ぶ。
同じ位相の場所が空間につくる面が「波面」、光が進む向きを表す線が「光線」である。
この平らな波では、光線は波面を正面から突き抜ける方向になる。

空気と水が接する水面に波面が斜めに届くと、一部が先に水へ入る。
先に入った部分から進む速さが小さくなり、波面と光線の向きが変わる。
これを、波面が水面へまっすぐ届いて向きを変えない場合と比較する。

水面へ届く光の一部は元の側へ戻り、一部は向こう側へ進む。
それぞれ反射光、屈折光と呼ぶ。
角度を比べる基準は、水面に90°で立つ線（法線）である。
光線図の全反射は、屈折する角度が取り得る範囲の限界とつながる。
基礎の干渉図は同じ振れ幅・周波数・偏り方向の二波が一つの場所で重なる例。
縞全体の分布は未実装。
波面図は透過する場合を扱い、反射と透過の強さの比・回折・分散は省く。
物質中の速さが決まる電磁的な詳細と、光の量子的な検出はこの先のテーマ。
力学を終える必要はなく、図から直接始められる。

## 数学は、関係を表す道具

| 関係を読みたい場面 | 必要になる表現 |
| --- | --- |
| 場所と向き | 座標・原点・正負 |
| 時間当たりの変化 | 単位 m、s、m/s、m/s²、グラフの傾き |
| 変化の積み重ね | 面積、長方形と三角形、二次関数 |
| 波面と進む方向 | 垂直・角度・比。式を読むときはsinと逆三角関数 |

数学の確認項目を本人の習得チェックリストにはしない。
必要になった場面の図や式に戻れるようにする。
3Dは奥行きや断面が必要になる教材で採用できる。
既存の図に足すこと自体を目標にしない。
可視化だけに限定せず、測定、観察、分類、資料の読み取りも世界を理解する入口として残す。
個人メモは任意で、気になった関係・参考資料・残る疑問を `notes/` に残せる。
