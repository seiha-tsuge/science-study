# 学びの地図

これは最初の学習ルート案です。興味に応じて順番を変えられます。
「実装済み」は教材があるという意味で、学習者が理解したという意味ではありません。

| 順序 | 問い | 必要な数学・表現 | 教材 |
| --- | --- | --- | --- |
| 1 | 同じ速度で進む物体の位置はどう変わる？ | 座標、単位、直線の傾き | `/mechanics/motion` 実装済み |
| 2 | 同じ割合で速度が変わると、位置はどう変わる？ | 変化率、二次関数、符号 | `/mechanics/acceleration` 実装済み |

| 4 | 質量を4倍にすると、ばねの周期は何倍？ | 三角関数、平方根、周期 | ばねの振動：今後の候補 |

| 6 | ランダムな動きと集団の広がりはどうつながる？ | 確率、平均、ばらつき | ランダムウォーク：今後の候補 |

## 概念のつながり

位置 → 位置の変化率としての速度 → 速度の変化率としての加速度 → 力と運動方程式。
位置と時間のグラフの傾きは速度。速度と時間のグラフの傾きは加速度。
波・電気・化学・生物・地学へは、必要な前提知識を整理してから枝を増やします。

## 数学に戻るチェック

本人が確認できた項目にチェックします。教材を実装しただけではチェックしません。

- [ ] 座標の原点と正方向を説明できる。
- [ ] 位置・変位・移動距離を区別できる。
- [ ] m、s、m/s、m/s² の違いを説明できる。
- [ ] 直線の傾きと速度を対応づけられる。
- [ ] 一定の速度と一定の加速度を区別できる。
- [ ] 速度と加速度の符号から、向きと速さの変化を説明できる。
- [ ] 時間の2乗と位置のグラフの曲がり方を対応づけられる。

## 実験以外の学び

可視化しやすい現象だけに限定せず、観察・分類・測定・資料の読み取りも学習範囲に残します。
入門教材の目次を1つ軸に選び、ここに対応する章を追記していきます。教材の選定は未定です。
式と定義の確認先として [OpenStax University Physics](https://openstax.org/books/university-physics-volume-1/pages/1-introduction) を参照できます。

後日の再確認では解説を閉じ、以前とは違う条件の結果と理由を説明します。
説明できなかった問いと必要な数学は、学習メモとこの地図に本人の言葉で追記します。
