## 教材への入口

`/` は分野と概念のつながり、`/mechanics` は道の上の場所・進む量・進み方の変化、`/optics` は水中のストロー・虫めがね・鏡の像を示す入口。
上の表の教材URLへも直接移れる。順序や回答の入力で閲覧を制限しない。
位置と速度では22秒の説明と出発点・速度の比較、加速度では長方形と三角形・時間と加速度の操作から運動の反転まで扱う。
反射・屈折では静止した観察から道筋へ、レンズ・鏡では同じ文字から紙に映る像とのぞく像の違いへ進む。
詳しい場面・条件・状態の設計と科学的な参考資料は各教材の `lesson.md`、実装・単位・時間制御は[アーキテクチャ](architecture.md)に置く。

## 力学の全体像

道の目印を0 mとし、物体の場所を数で表したものが「位置」である。
1秒に位置が何m変わるかを表す「速度」は、向きも含む。
さらに速度が毎秒どれだけ変わるかを見ると、「加速度」につながる。

毎秒同じ量ずつ位置が変わる場合、時刻と位置の点は直線に並ぶ。
速度が毎秒同じ量ずつ増える場合は、後の時間ほど進む量が大きくなる。
速度と時間のグラフでその量を足すと、長方形と三角形の面積として表せる。
三角形の底辺と高さが両方とも時間に比例するため、位置の変化に時間の二乗が現れる。
この先は力と加速度、慣性、運動量、エネルギーへつなぐ。
力の原因は現在の2題の範囲外。

## 光学の全体像

入口は水あり・なしで比べる、同じストローの見え方。
ストローと見る場所を固定し、水だけを変えて下側のつながり方を見る。
説明で同じ実際の下端へ戻し、目へ届く光、最後の向きを来た側へ延ばす補助線を段階的に加える。
水面で向きが変わることを見てから屈折と命名し、見える位置と実際の位置の違いを水中の石へつなぐ。
各点から同じ目の入口へ届く近接した光を使う局所的な近似で、写真・網膜像・コップ側面の歪みは再現しない。

人の列→水の山→光の目印→固定条件のストローは、速さと向きの理由をさらに調べる任意の説明。
A・B、到着順、進む距離、並びを保って対応させ、人の歩く向きは光の向きに対応させない。
列が傾くのを見てから、一様・等方的な物質で列に90°の光の向きを加える。
同じ速さと垂直入射では曲がらない比較も置く。

電場・磁場・干渉・位相の導入は、任意で開ける六場面に残す。
ひもの印と形の動きから電場へ移り、光の重なりの明暗を波として扱う手がかりにする。
繰り返しの一周を円で示してから位相と命名し、値の一致と位相の一致を比較する。
波面の断面と空間の面の切り替えも、この詳細で扱う。

水面へ届く光の一部は元の側へ戻り、一部は向こう側へ進む。
それぞれ反射光、屈折光と呼ぶ。
角度を比べる基準は、水面に90°で立つ線（法線）である。
光線図の全反射は、屈折する角度が取り得る範囲の限界とつながる。
基礎の干渉図は同じ振れ幅・周波数・偏り方向の二波が一つの場所で重なる例。
壁全体の縞の分布は扱わず、到着した二つの変化のずれを選んで比較する。
距離の作図では、同じ時間の進行距離と次の波面を三段階でつなぎ、0°と同じ速さで曲がらない場合も比べる。
波面図は透過する場合を扱い、反射と透過の強さの比・回折・分散は省く。
物質中の速さが決まる電磁的な詳細と、光の量子的な検出はこの先のテーマ。
力学を終える必要はなく、図から直接始められる。

凸レンズと平面鏡の教材は、同じ文字の縦線の上端Aから目へ届く光を入口にする。
紙だけを動かし、横から見た光の到着高さを、同じ紙の正面図へ対応させる。
一点の光が同じ場所へ届く関係から実像へ、下端Bを重ねて各点の対応と倒立へつなぐ。
虫めがねと鏡では、目に届く向きを来た側へ延ばし、見える位置と元の点を比較する。
平行な光で定める焦点の図は任意で開き、文字の像の位置と区別する。
砂地の人・水面の山・光の目印と90°の進行方向は、さらに曲がる理由を知る場面で対象の対応と限界を保って示す。
物が焦点にある場合は出た光が平行となり、有限の像はできない。
スクリーンの位置を像の位置から分けて操作し、一点の光が集まる面へ戻せる。
鏡では目だけの移動と物の移動を分け、変わる光路と変わらない対称位置を比べる。
虚像も目で見えるが、その位置に光が集まるわけではない。
平面鏡が面に直角な位置を反転する関係は、レンズの倒立像の回転と区別する。
薄いレンズと十分広い平面鏡の幾何学までを扱い、眼の結像や収差・回折はこの先へ残す。

## 数学は、関係を表す道具

| 関係を読みたい場面 | 必要になる表現 |
| --- | --- |
| 場所と向き | 座標・原点・正負 |
| 時間当たりの変化 | 単位 m、s、m/s、m/s²、グラフの傾き |
| 変化の積み重ね | 面積、長方形と三角形、二次関数 |
| 波面と進む方向 | 垂直・角度・比。式を読むときはsinと逆三角関数 |

数学の確認項目を本人の習得チェックリストにはしない。
必要になった場面の図や式に戻れるようにする。
3Dは奥行きや断面が必要になる教材で採用できる。
既存の図に足すこと自体を目標にしない。
可視化だけに限定せず、測定、観察、分類、資料の読み取りも世界を理解する入口として残す。
このサイトは現象を視覚的に理解する教材であり、ノート記録やメモ課題は設けない。
