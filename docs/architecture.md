# 設計と実験の追加

## 目的

科学の理解を深めることを目的に、1リポジトリ・1パッケージ・1アプリで育てる。
位置と速度、加速度、光の反射と屈折の3題を扱う。依存関係は必要になったものだけを追加する。
Three.js、MDX、グラフライブラリ、バックエンド、認証、ノート保存・同期は現時点では使わない。
共通のUIはMantine（`@mantine/core`・`@mantine/hooks`）を使用する。
`main.tsx`で標準CSSとMantineProviderを読み込み、`app/theme.ts`で色・文字・角丸を設定する。
ナビゲーション、カード、ボタン、選択肢、スライダー、表、初期条件の開閉にはMantineを使う。
独自CSSは教材のレイアウト、SVG・canvas、数式と説明演出に限定し、フォームやボタンの基本スタイルを再定義しない。
学習条件の確定や時刻制御は既存のReact状態とフックが担い、Mantineへ科学モデルを持ち込まない。

| 層 | 責務 | 持ち込まないもの |

共通部分は実際に2題で使うものだけに限定している。
`components/Lesson.tsx` は3題の学習の流れを共有し、分野の入口と参考資料をページから受け取る。
力学の既存2題は既定の分野・参考資料を使用する。
`Trajectory.observe(t)` は現在の2題を描画するための小さな契約で、全分野向けのモデル基盤ではない。
式の可視化・数値シミュレーション・実測データの可視化は、それぞれ教材に明記する。

## 時間と描画

モデルは解析式を評価する。数値積分の時間刻みはない。
再生には requestAnimationFrame のタイムスタンプの差を使い、フレーム数に依存させない。
描画は p5 の noLoop / redraw で現在の計算値を表示する。
0〜10秒の範囲で実行し、10秒で停止する。非表示のタブでは一時停止する。
時刻を直接指定したときも一時停止する。
条件を変えると実行部を再生成し、時刻0・停止状態に戻す。

ResizeObserver は canvas の表示幅だけを更新する。モデルに画面の大きさを渡さない。
p5 は動的 import し、未マウント後の初期化を防ぎ、離脱時に remove と observer の解除を行う。
React StrictMode の再マウントでも描画インスタンスを残さない。
グラフの軸は表示中の条件の0〜10秒の値から決定するため、条件を変えると縮尺も変わる。
比較表示中の2本のグラフは同じ縮尺を使う。

### 等速運動の説明アニメーション

`motion/ExplanationAnimation.tsx` は解説を開いたときだけマウントする。
React・SVG・GSAPと`@gsap/react`を使い、説明の22秒とモデルの物理時刻を分ける。
物理時刻は説明の2〜6秒に0〜4秒まで等倍で進み、それ以外の場面では停止する。
位置は既存の`observeMotion`で計算し、物体の座標に演出用のイージングを適用しない。
固定条件は x₀ = 0 m、v = 5 m/s。印とグラフは過去の0〜4秒の位置を振り返る。
SVGへの座標変換は表示側に置き、フレーム数から物理時刻を計算しない。
グラフの線が現れる演出は、物体の運動や追加の物理時間を表すものではない。

GSAPのタイムラインは停止状態で作り、再生・一時停止・初期化・任意の秒への移動を扱う。
場面の選択ではその場面の終了時刻へ移動して停止する。22秒で停止し、再生すると最初から始める。
非表示のタブでは停止する。解説を閉じるかページを離れると`useGSAP`のcontextが演出を破棄し、
visibilitychangeとメディアクエリのイベントリスナーも解除する。
動きを減らす設定では再生を無効にし、最終場面から静止画で各場面を確認できる。
共通の演出基盤や動画書き出しは追加していない。

`explanation-timeline.test.ts`では初期位置、運動中の一定速度、説明中の物理時刻の停止、
巻き戻し時の再現性を既存モデルと照合する。現実への適用範囲は既存の等速運動の前提に限る。

描画の矢印は速度の向きだけを示す。長さは速さに対応しない。
グラフは全10秒の式を先に表示し、縦のカーソルと点で現在時刻を示す。
canvas の代わりに読み取れる現在値の表と SVG の説明を用意する。

## 学習の流れと記録

### 光の反射と屈折

`/optics` を分野の入口、`/optics/reflection-refraction` を教材とする。
`model.ts` は角度をrad、速さをm/s、方向を単位ベクトルで計算し、画面の幅を受け取らない。
`Simulation.tsx` は角度・物質の選択と初期化を担当し、物理法則は実装しない。
`RayDiagram.tsx` はResizeObserverで幅を読み、モデルの方向をピクセルに変換する。
非表示の再生ループはなく、観察・初期化・再挑戦は静止した解析式の図で行う。
離脱時にobserverを解除する。p5、GSAP、共通の光学描画基盤や依存関係は追加しない。
同じ屈折率では反射光を描かず、全反射では屈折光を描かない。臨界角は境界に沿う限界として示す。
線の長さや太さを光の速さ・強さには対応させず、数値と成立条件を別に示す。
モデルのテストは既知の解・対称性・光路の可逆性・臨界角の境界を確認する。
実測で現実の水面やガラスへの適合を確かめたものではない。

### 共通の学習フロー

予想を選ぶまでは実験と解説を開けない。「まだ分からない」を選んでも進める。
予想は確定後に保持し、結果に合わせて書き換えない。
解説を閉じて説明したことを自分で確認してから、別条件の問題を解く。
自己申告と選択問題の結果を、学習の習得度の自動判定としては扱わない。
画面の選択はページ内だけで保持し、学習履歴は Markdown で残す。
AI は学習者本人の予想や理解の変化を捏造しない。

教材の確認用 Markdown と表示用 TSX の式・成立条件は同時に更新する。
個人の記録は `notes/journal/`、複数の実験を横断する理解は `notes/concepts/` に置く。

## 教材を追加する手順

1. `docs/learning-map.md` で前提知識と問いを決める。
2. `src/experiments/<分野>/<テーマ>/` に meta、lesson.md、model、model.test、Simulation、LessonPage を置く。
3. モデルは SI 単位で扱い、既知の解・不変量・対称性など科学的な期待値をテストする。
4. routes にページをつなぐファイルを加える。
5. 学習マップと分野ページに、概念のつながりを示す。
6. lint、型検査、テスト、ビルドを実行し、生成ルートも変更に含める。
7. ブラウザで予想・実験・停止・リセット・解説・再挑戦を一周し、狭い幅でも確認する。

数値積分を導入するときは、解析解との比較、刻みに対する収束、保存量の誤差を検証する。
確率的なモデルではシードと複数回の試行を扱う。実測では測定方法・単位・不確かさを残す。
テストで式の実装を確認することと、その式の現実への適用範囲を確認することは区別する。
