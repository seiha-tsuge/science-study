# science-studyの教材方針

## この文書の役割

science-study固有の目的、対象読者、利用者の継続要件、科学・光学の制約を定める。
分野をまたいで再利用する制作手順は[共通設計](content-design.md)、表現は[文章と図の規範](writing-guidelines.md)、記録の型は[テンプレート](templates/lesson.md)を正本とする。
実装・運用・追加手順は[アーキテクチャ](architecture.md)、学習範囲と接続は[概念の地図](learning-map.md)、コマンドは[README](../README.md#検証コマンド)に置く。
他リポジトリではこの設定を自分の目的と分野に合わせて定める。物理のSIモデルやこのサイトの画面契約は共通原則の必須前提ではない。

## 目的

世界の解像度を上げ、複雑な現象を生む関係について「なぜそうなるのか」を理解する支えを作る。
現実で見たり行ったりすることと科学の知識をつなぐ、個人のための実験室である。
対象は、抽象原理や専門語だけの説明では具体像を作りにくく、身近な現象から理由をたどりたい読者。既知の経験を決めつけず、場面自体を図と操作で示す。
計算結果、正誤判定、課題の完了をゴールにしない。

「なぜ」は深さを持つ。
関係から式の形が生まれる理由、現象を生むモデル上の仕組み、より根本の理論を区別する。
例えば等加速度から二乗が現れる理由を説明しても、力の発生まで説明したことにはならない。
屈折の波面の作図は速さと向きの関係を支えるが、物質中の速さが決まる電磁的な詳細までは扱わない。
各教材で扱う深さを示し、その先の見方につなぐ。

## 利用者の要望として継続して適用すること

光学一章の改修に限定せず、ホーム、分野ページ、すべての教材へ適用する。
抽象原理やレンズ図だけから入らず、コップの水を通してずれる見え方、眼鏡・コンタクトなど現実の疑問から理由をたどる。
現状で扱わない目の結像やコップ側面の歪みを、すでに説明できると約束しない。
共通設計の具体状況→関係→表現・抽象化→別状況への接続を、入口、図、操作、文章の構造に入れる。

- 最初に現実の行為、その中の現象、今回理解する関係と範囲を示す。ゴールを推測させない。
- 波・位相・波面などを未説明の前提にせず、図で見てから命名する。文章の言い換えや用語集だけで解決しない。
- 身近な現象を同じ対象のモデルへ移すことと別の物の比喩を分け、対応と限界を図・操作で示す。
- 図・アニメーション・必要な3Dや条件操作は、現象や関係の具体像を作るために選ぶ。
- 観察は自由。ノート・メモ課題・学習履歴、予想入力、理解度チェック、採点、必須の説明課題、完了判定を設けず、本人の理解や達成を自動評価・記録しない。設計・科学的根拠・開発検証は保存する。
- Mantine標準部品と共通テーマを使い、教材ごとのボタン装飾を増やさない。UXは説明順序、注目箇所、図と言葉、条件変更の分かりやすさで改善する。

利用者が以前の光学改善でUXと説明を評価し、その進め方の継続を求めたことを、方針の根拠として残す。
その評価を、全教材・全学習者に対する学習効果の実証へ広げない。
新しい概念の前提と具体像は、再度「イメージがない」と指摘される前に設計する。
方針を変える場合は利用者の明示要望を根拠にし、AGENTSとこの文書をそろえる。

## 表示と設計記録を結ぶ

4つの設計表を各教材の `lesson.md` に残し、表示と同時に更新する。
表の項目と画面の結合は次の契約で行い、教材カードも同じmetaのゴールを使う。

| 内容 | 表示用の契約 |
| --- | --- |
| 行為・そこで起きること・理解する関係・範囲 | `startingPoint.scene`・`overview`・`learningGoal.understand`・`learningGoal.scope` |
| 全体像と中心の問い | `startingPoint`・`question`・`relationships` |
| 関係が分かる図 | 必須の `mechanism` |
| 条件の比較 | `observation`・`simulation` |
| 式と前提・資料 | 任意の `explanation`、詳細を閉じても見える `sources` |
| 元の現象・別の日常・次の概念 | `connection`・`next` |

共通Lessonの既定表示は全体像→仕組み→条件→任意の式と前提。
反射・屈折は `opening` で水あり・なしを比べ、同じ水の条件を説明へ渡す。光線図・波・人の比喩を入口の前提にしない。
どの節にも直接移れ、回答で閲覧を制限しない。
`LessonContent` の必須項目、共通Lessonの構成検査、`tests/lesson-design.test.ts` の4つの設計表の構造検査を組み合わせる。
後者は教材ページを自動で探索し、記録の欠落・空欄・未記入、配置・状態の列を検出する。
構造がそろうことと、説明が科学的に正しく分かりやすいことは分けてレビューする。
追加手順・ファイル名・コマンドはアーキテクチャとREADMEを参照する。

## 科学を説明する範囲

科学的な正確さ、理解の足場、注意の配分、日本語の順で優先する。
モデルはSI単位で計算し、単位、尺度、近似、成立条件、正負と方向の基準、省略、参考資料を示す。
解析式、数値シミュレーション、実測、模式図、比喩を区別する。
説明の緩急を物理的な運動のイージングや速さの変更に置き換えない。
物理時刻・説明時間・フレーム数を分ける実装規則はアーキテクチャに置く。
力学では同じ物体・時刻の道とグラフを対応させ、別の比喩を必須にしない。
力学の2Dや光学のSVG投影図に、目的なく3Dを追加しない。
実測によるモデルの適合や学習効果を確認していない場合は、その旨を報告する。

## 光学で保つ具体像と区別

主な入口は同じストローの水あり・なし。物と見る場所を固定し、水だけを変える。
同じ実際の下端へ戻り、目へ届く光→幾何学的な延長→見える位置の順に加え、向きの変化を見てから屈折と呼ぶ。
水中の石へ戻し、各点の局所近似、写真・網膜像・曲がったコップ側面を含まない範囲を示す。
人の列と波は、速さと向きの理由をさらに調べる任意の説明に置く。

### 用語を使う前に見せるもの

| つまずく説明 | 必要な具体像・区別 |
| --- | --- |
| 「光線は波が進む方向を表す線」 | まず波では何が変わり、何が伝わるかを見る。光では何の変化を表しているかと、波として扱う観察の手がかりを示す。 |
| 「同じ位相」 | 繰り返しのどの段階かを見る。同じ値でも、その後に上がる場合と下がる場合を比較する。 |
| 「同じ位相の場所を結ぶ」 | 条件に合う場所を図で選び、連続した集合として示す。「位相がない場所」や、実在する糸でつながった場所と混同させない。 |
| 「波面」 | 同じ進み具合の場所が空間で面になる様子と、その断面を対応させる。実在する物質の表面とは区別する。 |
| 「その方向に垂直」 | 対象となる線・面・矢印を名前で指す。波面に垂直な光の向きと、水面に垂直な基準線を別々に示す。 |
| 「斜めの波面が物質の境界に入る」 | 空気と水が接する水面と、そこへ到達する波面を描き分ける。一部が先に届く様子から、向きの変化をたどる。 |

### 任意の波と人の列の説明

`RefractionJourney` はストロー → 人の列 → 波の目印と光の向き → 同じストローの四場面を切り替える。
人の列は到着順・同じ時間に進む距離の違い・列の傾きの関係を示す。
波の図への切り替えではA側・B側の配置を保ち、列に90°の光の向きを別の段階で加える。
人の歩く向きを光へ対応させず、たとえから科学の性質を導いたことにしない。
入口と着地点の同じストローの図に実際の光路と逆向きの延長を重ね、実際の点と見える点を対応させる。
電場・干渉・位相を含む `WavePrimer` の六場面は任意の詳細とし、本筋の前提として要求しない。
一度に一つの場面を表示し、名前と短い説明を同じ図の近くに置く。
同じ高さでも変化の向きが異なる例を、同じ位相の例と並べる。
波面は上からの断面と奥行きのある面を同じ例で切り替え、「光線の向きに90°」と「水面に90°の法線」を区別する。
幾何学の作図は任意で開く。

ひもでは物質が上下するが、光の電場のグラフの高さは物体の位置ではない。
主な説明と任意の図の固定条件や状態の独立性は、各教材の設計記録とアーキテクチャに記す。

## 結像の教材で確認すること

像の説明は、物全体の光が一つの点へ集まるように書かず、物の一点と像の一点の対応を図で示す。
先端と根元など、同じ二点を保ったまま像の向きと大きさへつなぐ。
実際の光路と、出た後の向きを逆に延ばした幾何学の線は線種で分ける。
虚像が見えることと、スクリーンへ直接映せないことを区別し、目の別のレンズによる結像とも分ける。

焦点は平行な光で決まる目印として導入し、一般の物の像の位置と混同しない。
像の位置、スクリーンの位置、目の位置の役割を分け、一つの変更でほかの条件を勝手に追従させない。
焦点ちょうどや描画範囲外を通常の有限の像として見せず、式と図で境界の意味を示す。
縮尺や見る断面が変わる場合は、図の近くに明記する。

一回のレビューで表の完成を判定せず、次の観点で実装へ戻る。
まず前提・各点の対応・境界条件を資料と式で照合し、次に場面ごとの名前の導入と因果の中間段階を図で指す。
最後に実画面で条件と表示の同期、変わらない条件、狭い画面とキーボードを確認する。
修正した配置と状態を設計表へ戻し、レビューの指摘と修正、確認できた範囲を lesson.md に残す。

「上下左右が逆」とだけ書かず、図がどの断面を示すか、どの軸でどの位置が変わるかを示す。
レンズの倒立像の回転と、平面鏡の面に直角な位置の反転は区別する。
焦点ちょうどの平行な光や図の外の像も、現在の条件に対応する文章で説明する。
「虚像」は見えない像の意味として使わない。

## 文章改善の具体例

| 書き直す前の説明 | 対象と関係を補った説明 |
| --- | --- |
| 速度はグラフの傾き | 横に時間、縦に位置を置く。右へ1秒進むごとに5 m高くなる割合が傾きで、速度5 m/sに対応する |
| 速度と時間の面積は変位 | 速度2 m/sが1秒続くと2 m進む。高さが速度、幅が時間の長方形でこの量を表し、時間を細かく分けて足すと面積になる |
| 波面は同じ位相を結ぶ面 | 電場の繰り返しが同じ段階にある場所を緑で示す。この連続した場所の集まりを、断面と奥行きのある面で見せてから波面と呼ぶ |
| 条件を変えて観察しましょう | 速度だけを変えると1秒に進む量が変わる。青い点と灰色の輪を同じ時刻で比較できる |

式や単位、資料の名称、意味が明確な短いラベルは、その表記を保つ。
