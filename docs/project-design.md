# science-studyの教材方針と範囲

## 文書の役割

この文書は、science-studyの目的、読者、教材の範囲と科学上の制約を定める。
教材の一覧と概念のつながりを、この目的に照らして示す。
分野をまたいで使う制作原則は[共通の教材設計](content-design.md)、文章の規範は[文章と図の規範](writing-guidelines.md)を参照する。
部品の責務は[アーキテクチャ](architecture.md)、実装と公開の手順は[開発ガイド](development.md)、実行コマンドは[README](../README.md#検証コマンド)に置く。

## 現実の疑問と科学をつなぐ目的

science-studyは、身近な現象を生む関係を、図と操作でたどる個人のための教材である。
抽象原理や専門語だけでは対象を思い描きにくい読者が、歩くことや道具をのぞくことから理由へ進めるようにする。
読者がすでに経験したとは決めつけず、見る対象と場面を画面に示す。
計算問題の正答や課題の完了を学習のゴールにはしない。

この目的は、ホーム、分野の入口と全教材に共通する。
利用者は日常と知識の接続を求めており、身近な名詞を添えるだけの導入や、操作前から点と数値を追わせる説明では足りない。
同じ物、道具、見る場所を保ち、見え方や動きから必要な関係へ移す。
目の結像やコップ側面の歪みなど、実装していない現象を説明できると案内しない。

説明する理由には段階がある。
等加速度から時間の二乗が現れる説明は、力が速度を変える理由までを示すものではない。
同様に、屈折の作図は速さと向きの関係を示すが、物質中の光の速さを決める電磁的な仕組みまでは計算しない。
各教材は説明できる深さを示し、未実装の接続先は候補として区別する。

## 教材の範囲

現在は、運動の二題と光学の二題を公開URLに接続している。
次の表の「実装済み」は教材の存在を表し、読者の理解や学習効果を判定した意味ではない。
どの教材からも始められ、回答の入力や順序による閲覧制限はない。

| 中心の問い | 扱う関係 | 図と操作 | 教材 |
| --- | --- | --- | --- |
| 同じペースの歩行は、グラフでどう表せるか | 位置、速度と変位の対応 | 等間隔の位置の印、動きとグラフ、出発点と速度の比較 | `/mechanics/motion` 実装済み |
| 速くなる車の移動に、時間の二乗が現れるのはなぜか | 変化率と変化の積み重ね | 長方形と三角形、時間と加速度、等速運動との比較 | `/mechanics/acceleration` 実装済み |
| ストローは、どうして曲がって見えるか | 届く光の向きと見える場所 | 水だけを変える比較、同じ下端の光路と補助線 | `/optics/reflection-refraction` 実装済み |
| 虫めがねや鏡で、葉の見え方が変わるのはなぜか | 屈折、反射と像の位置 | 同じ葉と道具、境目、目へ届く光を段階表示 | `/optics/lenses-mirrors` 実装済み |
| 横と縦に分けても、一つの運動を表せるのはなぜか | 成分の独立と合成 | 軌道と成分の同時表示 | 放物運動：候補 |
| 元へ戻る力から、往復する動きが生まれるのはなぜか | 平衡、復元と慣性 | 力、速度、位置、位相とエネルギー | ばねの振動：候補 |
| 波の重なり方で、強さが変わるのはなぜか | 重ね合わせと位相 | 二つの波と合成波 | 波：候補 |
| 不規則な個々の動きから、集団の規則性が生まれるのはなぜか | 個体、集団、分布と尺度 | 多数の軌跡と分布 | ランダムウォーク：候補 |

ホーム `/` は教材と分野の入口、`/mechanics` は運動、`/optics` は見え方と光の入口である。
各教材の詳しい場面、モデル、固定条件と参考資料は、教材フォルダの `lesson.md` を参照する。

### 力学の概念のつながり

道の目印を基準に、物体の場所を数で表す。
その数を**位置**、単位時間あたりにどちらへどれだけ位置が変わるかを**速度**と呼ぶ。
「速度」が単位時間あたりに変わる割合へ注目すると、**加速度**につながる。

毎秒の位置の変化が同じなら、時刻と位置の点は直線に並ぶ。
一方、速度が毎秒同じ量ずつ増える場合は、後の時間ほど進む量が大きくなる。
速度と時間のグラフでは、その量を初速度の長方形と、増えた速度の三角形に分ける。
三角形の底辺と高さがともに時間に比例するため、変位の式に時間の二乗が現れる。
力、慣性、運動量とエネルギーは、この二題の先のテーマである。

### 光学の概念のつながり

水中のストローと道具を通した葉の見え方を入口にする。
物から目へ届く光が境目でどう変わるかを示し、物自体の場所と見える場所を区別する。
光の進む速さが異なる物質へ斜めに入るときの向きの変化を**屈折**、元の側へ戻ることを**反射**と呼ぶ。
虫めがねでは二つの表面、鏡では反射する面を先に示し、光の線を説明なく折り曲げない。

光の届く向きと、見える物の場所を対応させてから、その姿を**像**と呼ぶ。
実際に光が集まる場所へ紙を置いて受ける**実像**と、届く向きを来た側へたどって求める**虚像**を区別する。
「虚像」は見えないという意味ではなく、そこへ光が集まるわけではないという区別である。
目やカメラの別のレンズが、届いた光を網膜やセンサーへ集める過程とも分ける。

屈折の理由をさらに調べる場合は、人の列、波の目印と光の向きを対応させる任意の説明へ進める。
人の歩く向きは光に対応せず、到着順、同じ時間に進む距離と列の傾きだけを引き継ぐ。
電場、干渉、位相と波面の詳細も任意であり、日常の見え方をたどる前提にはしない。
眼鏡やコンタクトの補正は眼の結像を要するため、現在の主な題材には含めない。

## 科学的な条件と区別

科学モデルはSI単位で計算し、式、単位、正負の基準、尺度、近似と省略を示す。
解析式の評価、数値シミュレーション、実測と模式表示は、それぞれ何を求めた結果かを書く。
物理時刻と説明時間を分ける実装規則はアーキテクチャに定める。
実測への適合と学習効果は、その検証を行った場合だけ方法と範囲を報告する。

光学の図は、次の比較で読み違いを防ぐ。

| 対象 | 図で分けるもの |
| --- | --- |
| 水面越しの見え方 | 実物と局所的な近似位置。ガラスの曲面、写真、網膜像は別のモデルを要する |
| 光路と補助線 | 実際に進む実線と、場所を探す破線。目から光を出す説明にはしない |
| 波の目印 | 変わる物理量と物質の移動。光の電場の高さを物体の位置に対応させない |
| 位相 | 一周期の進み具合と瞬間の値。同じ高さでも上がる場合と下がる場合がある |
| 波面と法線 | 波の同じ段階の場所がつくる面と、水面に90°の基準線。実在する糸で結ばれた面ではない |
| 焦点と像 | 平行な光で定める目印と、近くの物の像の場所 |
| 鏡とレンズの反転 | 鏡の面に直角な位置の反転と、レンズの倒立像。「上下左右が逆」と一括りにしない |

薄いレンズは軸に近い光と小さい角度、鏡は十分広い平面鏡を仮定する。
焦点ちょうどや描画範囲外の像を、通常の有限の像として描かない。
収差、回折、明るさ、目のピント調節と脳による奥行き判断は、現在の見え方のモデルでは再現しない。

## 表示と設計記録の対応

教材ページは、四つの設計表を画面と同時に更新する。
表の構造は[テンプレート](templates/lesson.md)、制作原則は共通の教材設計に定め、ここではscience-studyの表示キーとの対応だけを示す。

| 記録する内容 | 表示の対応先 |
| --- | --- |
| 行為、現象、理解する関係と範囲 | `startingPoint.scene`、`overview`、`learningGoal.understand`、`learningGoal.scope` |
| 中心の問いと概念の関係 | `question`、`startingPoint`、`relationships` |
| 関係をたどる図と観察 | `mechanism`、必要に応じた `opening` と `overviewVisual` |
| 条件の比較 | `observation`、`simulation` |
| 式、前提と参考資料 | 任意の `explanation` と、閉じても見える `sources` |
| 元の現象と接続先 | `connection`、`next` |

教材の構成検査はゴールの表示順、入口間の一致と回答による制限がないことを確かめる。
設計表の検査は欠落と空欄を検出するが、説明の意味と科学的な妥当性はレビューで照合する。
検査の実行手順は開発ガイドに置く。

## 数学を使う場面

必要な数学は、現象の関係を読む場面へ対応させる。
座標は場所と向き、傾きは時間当たりの変化、面積は変化の積み重ねを表す。
光学の作図では垂直、角度と比を使い、式の詳細でsinと逆三角関数を説明する。
これらを読者の習得チェックリストにはせず、必要になった図へ戻れるようにする。
奥行きや断面を2Dで示せない場合は3Dを検討できるが、既存の図へ足すこと自体を目的にはしない。
観察、測定、分類と資料の読み取りも、可視化と同様に世界を理解する入口になる。
